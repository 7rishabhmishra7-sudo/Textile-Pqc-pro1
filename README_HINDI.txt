TEXTILE PQC PRO - ANDROID PROJECT

यह Android app Weaving PQC Excel से Process PQC Excel तैयार करता है।

Features:
- Weaving PQC .xlsx upload (SHEET-1)
- Buyer, Invoice No., GSM, Invoice Quantity, Spinning+Weaving Loss, Process Loss और Applied Net Quantity input
- Consumed Quantity के अनुपात में required fiber allocation
- Accessories/Sizing/Filling = 0 और Product Weight = Applied Net Quantity
- Original blank Process PQC template के merged cells, formatting और row-12 formulas सुरक्षित
- Generated Excel को Android file picker से save करना

Build: GitHub Actions workflow build-from-zip.yml के माध्यम से APK build करता है।
Package ID: com.rishabh.textilepqcpro (Textile QA Pro से अलग)
